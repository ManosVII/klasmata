# Μαθηματικά με Κλάσματα

Εκπαιδευτικό παιχνίδι για τα κλάσματα, για μαθητές Ε΄–ΣΤ΄ Δημοτικού. Είναι κατάλληλο και για παιδιά με μαθησιακές δυσκολίες.

**Παίξτε εδώ:**https://manosvii.github.io/klasmata/
## Τι περιέχει
- 16 κατηγορίες:
  - ισοδύναμα με πίτσες
  - πράξεις κλασμάτων
  - μετατροπές
  - απλοποίηση
  - δεκαδικά κλάσματα
  - προβλήματα
  - αναγωγή στη μονάδα
  - σύγκριση
  - ταξινόμηση
  - αναγνώριση κλάσματος
  - αριθμογραμμή
  - ισοδύναμα με κενό
  - πράξεις με μεικτούς
  - κλάσμα και ποσοστό
  - κλάσμα ως διαίρεση
  - μικτή εξάσκηση
- Τρία επίπεδα δυσκολίας, παιχνίδι Solo και VS (δύο παίκτες).
- Επίπεδα, XP, επιτεύγματα και βραβεία.
- Βοήθεια και εικόνες μετά από λάθος, και σύνοψη στο τέλος κάθε γύρου.

## Τα δεδομένα των μαθητών
- **Πού μένουν τα προφίλ:** μόνο στον browser κάθε συσκευής. Τίποτα δεν στέλνεται στο διαδίκτυο.
- **Για μεταφορά σε άλλη συσκευή:** «💾 Αποθήκευση» και μετά «📂 Φόρτωση» στη νέα συσκευή.
- **Προσοχή:** μην ανεβάζετε σε αυτό το αποθετήριο αρχεία `math_fractions_profiles.json`, γιατί περιέχουν ονόματα μαθητών.
